# Retail Demand & Financial Planning Analytics

## Project Overview
An end-to-end analytics project exploring retail demand
forecasting, revenue planning, and operational decisions.

## Objectives
- Build a reproducible SQL data pipeline.
- Analyze retail sales and pricing data.
- Forecast product-level and store-level demand.
- Model financial and operational scenarios.
- Communicate business recommendations.

## Technology
- Python (Pandas, NumPy, Scikit-learn)
- SQL (DuckDB)
- Git and GitHub

## Data
M5 Forecasting dataset.

Raw data is excluded from version control.
